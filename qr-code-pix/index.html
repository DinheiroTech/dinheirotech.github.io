Gerador de QR Code PIX (Copia e Cola)

Gerador de QR Code PIX que nasceu junto com o PIX no Brasil.

Gratuito • Confiável • Sem cadastro • Com privacidade desde 16 de novembro de 2020.

Pode ser aleatória (EVP), e-mail, telefone, CPF ou CNPJ. Para CPF/CNPJ utilize apenas números sem pontuação.

Use ponto como decimal.

Use *** para automático. Alguns bancos exigem autorização para TXID customizado.
