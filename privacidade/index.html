Política de Privacidade

Última atualização: Março de 2026

O dinheiro.tech é um site de ferramentas financeiras gratuitas e de uso imediato. Nosso compromisso é com a transparência e a privacidade do usuário. Esta política explica como lidamos (ou não lidamos) com seus dados.

1. Não coletamos dados pessoais

Não coletamos, armazenamos nem processamos qualquer tipo de dado pessoal identificável (nome, e-mail, CPF, IP, localização, histórico de navegação, etc.) em nossos servidores.

Todo o processamento (cálculos, decodificação de BR Code, consultas a APIs públicas) ocorre exclusivamente no seu navegador (client-side).

Exceção (à regra de processamento de dados no navegador): Gerador de QR Code PIX
Para gerar o código BR Code PIX (payload EMV), os dados que você digita (chave, valor, nome do beneficiário, cidade, descrição, identificador) são enviados temporariamente para um endpoint em nosso servidor, com o único propósito de montar o BR Code e devolvê-lo imediatamente ao seu navegador.

Esses dados:

  • São processados apenas para montar o BR Code e devolvê-lo imediatamente;
  • Não são armazenados em banco de dados, logs persistentes ou compartilhados com terceiros;
  • São recebidos apenas pelo tempo da requisição (segundos);
  • Incluem seu endereço IP (como qualquer requisição HTTP).

Esse endpoint é parte de um MVP/exemplo público e open-source da biblioteca que desenvolvi: https://github.com/renatomb/php_qrcode_pix.

Não mantemos acesso nem guardamos chaves PIX, nomes, valores ou qualquer informação após a resposta ser enviada.

2. Comunicação direta com APIs públicas

A maioria das ferramentas (cotações, cálculos) ocorre exclusivamente no seu navegador, sem passar pelos nossos servidores. O seu navegador faz requisições diretas às APIs públicas:

  • Banco Central do Brasil (BACEN)
  • Binance
  • NovaDAX

Essas requisições não passam pelos nossos servidores. Não temos acesso ao conteúdo delas.

3. Google Analytics (com restrições)

Usamos Google Analytics (GA4) de forma limitada para entender o uso do site (número de visitas, páginas mais acessadas, fontes de tráfego). Não coletamos nem armazenamos dados pessoais identificáveis.

Configurações aplicadas:

  • IP anonimizado
  • Restricted Data Processing ativado
  • Sem remarketing ou publicidade personalizada
  • Sem cruzamento de dados com outros produtos Google

Você pode bloquear o Analytics a qualquer momento usando extensões como uBlock Origin ou desativando JavaScript para o domínio googlesyndication.com.

4. Cookies e tecnologias de rastreamento

Não usamos cookies próprios para rastreamento. O Google Analytics pode definir cookies técnicos (anônimos) apenas se você não bloqueá-los.

Não há cookies de terceiros para publicidade ou profiling.

5. Links externos e APIs

O site contém links para serviços externos (ex: Buy Me a Coffee, APIs públicas). Não controlamos a privacidade desses serviços. Recomendamos ler as políticas deles.

6. Alterações nesta política

Podemos atualizar esta política para refletir mudanças no site ou na legislação. A versão mais recente estará sempre nesta página, com data de atualização.
